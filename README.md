# 🍏 BiteRush: Sobrevivência Nutricional

**O "anti-app de dieta".** Um arcade hipercasual de reflexo rápido focado em retenção orgânica, combinando a dopamina clássica de jogos de pontuação (High Score) com conscientização sobre alimentação saudável.

🕹️ **[JOGUE AGORA NO NAVEGADOR (Mobile & Desktop)](https://seu-usuario.github.io/biterush-game/)** *(Coloque o link do seu GitHub Pages aqui!)*

## 🧠 A Tese do Produto (Core Loop)
Aplicativos de nutrição tradicionais têm atrito altíssimo e churn de 70% no primeiro mês. **BiteRush** inverte essa lógica: em vez de contar calorias em formulários chatos, o usuário precisa ter reflexos rápidos para:
1. **Coletar comida limpa (Frutas/Vegetais):** Aumenta os pontos e recompensa com feedback visual e sonoro positivo.
2. **Desviar de ultraprocessados (Junk Food):** Capturar lixo aumenta a barra de "Toxidade". O avatar incha visualmente, a velocidade de movimento despenca e a tela treme.
3. **Coletar Superalimentos (Água):** Limpa o organismo instantaneamente, zerando a toxidade e recuperando a velocidade máxima do avatar.

## 🚀 Tecnologias e Arquitetura do MVP
- **HTML5 Nativo + Phaser 3 (Engine):** Escolhidos estrategicamente para garantir peso zero de download, latência de toque otimizada (<16ms) e carregamento instantâneo.
- **Gráficos procedurais via código:** O jogo foi desenhado sem dependência de pastas de `.png` ou `.jpg`, permitindo hospedagem simples num único arquivo para este MVP de validação.
